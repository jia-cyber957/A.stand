# A.stand v2 产品定义与路线图

## 1. 产品定位
**A.stand v2** 是一个运行在本机后台的**多上游常驻子 Agent 调度桌面软件**（仿 Magpie / CC Switch 轻桌面体验）：
- **上游注册制接入**：任何支持 MCP 的 AI 客户端（Antigravity、Codex CLI、Claude Code、Cursor、WorkBuddy 等）均可接入同一个常驻 A.stand 后台，共享持久化子 Agent（白泽 Oracle / 祝融 Hephaestus）、Prompt Cache 与模型队列；关闭任意上游窗口不会杀死后台正在执行的子 Agent。
- **通信策略**：首选本地 **Streamable HTTP**（`http://127.0.0.1:3426/mcp` + 专属注册码），内置轻量 **`stdio-bridge.mjs` 命令行传话桥**兜底（解决 Cursor 本地 HTTP 偶发 OAuth 弹窗或旧客户端兼容问题）。
- **零门槛接入方式（v2.0）**：在桌面端点击 **「+ 接入新上游」** 生成专属注册码与**一键复制 AI 接入 Prompt**，直接粘贴给上游 AI 让它自行完成 MCP 配置与首次握手；首次握手后自动匹配内置品牌图标，并允许手动改名/换图标/停用/重置密码。

## 2. 核心页面与功能闭环（v2.0 已实现）
1. **已接上游**：单行开关卡片、搜索与密码打码、已停用折叠区、`+ 接入新上游`（AI 接入 Prompt / HTTP JSON / stdio 桥三标签 + 实时握手变绿）、详情抽屉（改名/换图标/重置密码/删除）。
2. **实时任务**：运行中与近期任务（带上游来源标签）、时间线透视抽屉、手动停止、崩溃中断恢复横幅。
3. **角色与队列**：全局总开关、白泽（只读并行）与祝融（可写/Git Worktree 并行）模型优先队列（支持备选位原地点击更换）、智能选型、推理档位动态映射、可编辑角色常驻守则、持久会话管理（压缩/重置）。
4. **技能与扩展**：三分栏军火库（`Skills 技能` / `子 Agent MCP` / `模板与产物`），预置「单文件红线与模块化」「测试防作弊护栏」两条默认开关，支持导入本地 `SKILL.md` / 文件夹，并按角色选择「常驻注入」或「按需读路径」。
5. **模型供应商**：CLI 引擎探针（Codex 含 5h/7d 额度条、DeepSeek Harness 等）、自定义 API 渠道 CRUD、模型拉取与连通性测试。
6. **缓存与耗时**：Prompt Cache 累计命中率与趋势图、`job-perf.jsonl` 耗时账本、未上报缓存原因提示。
7. **全局设置**：并发上限、静默/长任务巡检（支持中途动态生效）、卡顿守门员 AI、Worktree 并行写、后台异步门铃、浅/深色主题、中英文切换，以及 **「一键导出脱敏诊断包（`.zip`）」** 与 **「打开日志目录」**。
8. **原生桌面壳（方案 A）**：Tauri 2 轻窗口 + Windows 系统托盘常驻（`a-stand.exe` ~6.3 MB，点 `×` 隐藏至托盘不杀后台，右键托盘退出才停止守护进程）。

## 3. v2.0 明确暂不做（后续演进路线）
- **主流 IDE 一键自动写配置适配器**（v2.0 统一用「一键生成 AI 接入 Prompt」过渡，v2.1+ 按需补充）。
- **自定义新建子 Agent 角色与可控嵌套调用（套娃开关）**（v2.0 保持白泽/祝融双核心轻巧稳定，v2.1+ 扩展）。
- **软件内自动迁移旧插件数据**（保持软件纯净无历史包袱，本机按需手动复制数据目录）。
- **`agy` / `claude-code` 引擎深度成熟化改造**（当前聚焦 Codex CLI + DeepSeek Harness ACP）。
