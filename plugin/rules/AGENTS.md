# Agent Relay Delegation Gate

While the `agent_relay_*` tool set is available it brokers two persistent external specialists: `oracle` (read-only advisor/reviewer) and `hephaestus` (workspace-write engineer). These rules are host-agnostic.

1. **Master Switch ON = Actively Offload to Save Lead Quota**: proactively delegate without waiting for the user — heavy multi-file edits (3+ files) and long refactors -> `agent_relay_ask(role="hephaestus")`; deep investigation, architecture tradeoffs and independent review -> `agent_relay_ask(role="oracle")` / `agent_relay_review`; any bug that failed 2+ fix attempts -> `oracle`. Handle trivial 1–2 file edits and quick lookups yourself.
2. **No Substitute Subagents**: never route work `oracle`/`hephaestus` can do to the host's own generic subagents; reserve host-native specialists for host-only capabilities (interactive browser UI, image generation).
3. **True Parallel & Explicit Sessions**: for 2+ independent read-only investigations launch each `oracle` with `waitSec: 0` and a distinct `slot`, then collect them in one `agent_relay_poll(jobIds=[...])`. Omit `sessionId` (new task); on follow-ups pass the footer `sessionId` with a delta-only prompt.
4. **Async Doorbell Flow (only when `agent_relay_session(action="status")` reports `limits.asyncBackgroundMode: true`)**: call `agent_relay_ask` WITHOUT `waitSec` -> copy the returned `Doorbell (zero-token background wakeup): node "<dist>/wait-job.mjs" --data-dir "<dataDir>" <jobId>` line -> run it as a background command (`WaitMsBeforeAsync=500`) -> end the turn with `⏳ 后台运行中... 请勿关闭 Antigravity`. When the doorbell wakes you: if the user is idle, auto-verify the result and report it; if the user is actively chatting about topic B, answer B first and append a one-line `🔔 job <id> 已完成 ...` notice asking whether to review A. Exit codes: `0` completed, `1` failed/interrupted, `2` stall, `3` MCP process died.
5. **Non-Interrupting Check-ins**: `silent_checkin` / `long_run_checkin` / `running_checkin` mean the subagent is still running untouched — inspect (`agent_relay_poll(..., detail="full")` or the job log), then keep polling, `action="steer"` (Codex), or `action="interrupt"`.
6. **Safety Guardrails**: `master switch is OFF` -> never retry, finish solo. `[ALL_ENGINES_EXHAUSTED]` / `fallback_confirmation_needed` -> pause delegation, show reset countdown / options, wait for the user. Never write to a workspace while a `hephaestus` job runs there. After a host crash the Team panel shows an `⚠ 意外中断` banner — resume with the copied `sessionId` prompt.
7. **Coding Prompts**: always include explicit test timeouts (e.g. `go test -timeout 30s`, `vitest run --testTimeout=20000`) so a hung subagent test fails fast instead of stalling the job.
